## 10. Admin Realtime Concurrency & Distributed Architecture Analysis

- **In-Memory SSE EventBus:** Centralized in-memory reactive event stream with replay buffer for single-instance / long-running Node.js deployments.
- **Serverless Architectural Reality:** In serverless / multi-region deployments (e.g. Vercel Serverless Functions), lambdas do not share memory across parallel invocations. For enterprise scale with multiple concurrent servers, an external Redis Pub/Sub (e.g., Upstash Redis) or database webhook listener is recommended.
- **Heartbeat Keepalive:** Automated SSE keepalive comments transmitted every 15 seconds preventing gateway proxy timeouts.

## 11. Database Concurrency & File Storage Invariants

- **Single-Server Mutex File Locking:** `repository.ts` employs atomic `fs.promises` read/write locks preventing race conditions during concurrent local development.
- **Production Scalability Roadmap:** For large-scale distributed transaction concurrency, migration to a hosted PostgreSQL/Supabase database with ACID row-level locking (`SELECT ... FOR UPDATE`) is the recommended production path.
